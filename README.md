# 🐾 Sons de Animais

Projeto feito para tocar **sons de animais** 🐶🐱🐷🦁.

Cada botão mostra a imagem de um animal e, ao clicar ou pressionar **Espaço**, o som correspondente é reproduzido.  
Além disso, o layout tem um fundo de mudanças de cor, para trazer uma experiência mais confortavel e bonita.

---

## Tecnologias usadas
- **HTML** → estrutura da página
- **CSS** → estilos
- **JavaScript** →interação e reprodução dos sons

---

## Como usar
1. Clique nas imagens para tocar o som do animal referente.
